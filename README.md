# System Design Handbook

Interview-focused system design: 39 concept chapters and 10 case studies, with interactive SVG diagrams.

```bash
python3 build.py                  # writes site/; open site/index.html
python3 check.py --run-snippets   # lint every chapter and run its Python examples
```

Chapters live in `content/<slug>.html`; the chapter list and order live in `PARTS` in `build.py`.
See `CONTRIBUTING.md` for how chapters and diagrams are written.
